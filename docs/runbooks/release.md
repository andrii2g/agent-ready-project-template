# Release Runbook

1. Confirm the target commit and release scope.
2. Confirm required CI and policy checks pass.
3. Review dependency, security, compatibility, and migration effects.
4. Update version, changelog, documentation, and upgrade guidance.
5. Build and verify artifacts in a clean environment.
6. Obtain explicit human approval.
7. Publish through the approved release mechanism.
8. Verify installation or deployment and monitor for regressions.
9. Record rollback steps and release evidence.

Agents may prepare release material but must not publish a release by default.
