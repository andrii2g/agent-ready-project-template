# Changelog

All notable changes to this project are documented here. The format follows
Keep a Changelog principles and uses semantic versioning.

## [0.2.0] - 2026-07-18

### Added

- Complete Claude Code project layer with root `CLAUDE.md`, shared settings,
  project subagents, modular rules, synchronized skills, deterministic hooks,
  optional output-style guidance, and local override examples.
- Active, empty `.mcp.json` plus an MCP trust-boundary review guide.
- Generic, Python, TypeScript, Go, and Rust project blueprints.
- Guarded project initializer, repository verifier, skill synchronizer, GitHub
  configuration helper, deterministic tree renderer, and template-tool tests.
- GitHub issue forms, pull-request template, CODEOWNERS, CI, policy checks,
  Dependabot, optional security workflows, labels, and ruleset configuration.

### Security

- Human approval gates for publishing, dependency changes, infrastructure tools,
  and agent-governance edits.
- Secret-path restrictions and tested pre-tool hooks for destructive commands
  and sensitive file access.
- Sandboxed Codex and Claude defaults with broad network/tool integrations
  disabled until explicitly reviewed.

## [0.1.0] - 2026-07-18

### Added

- Initial language-agnostic agent-ready project template concept and shared
  `AGENTS.md` contract.
